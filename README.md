# Story 2: Federal Reserve Dual Mandate

This project examines whether the Federal Reserve has been able to maintain stable inflation and low unemployment over the past 25 years.

The analysis uses monthly CPI and unemployment data from the Bureau of Labor Statistics API and the federal funds rate from the FRED API. The visualizations were created in R using ggplot2.

## Files

* `Federal_Reserve_Dual_Mandate_Analysis.Rmd` contains the complete R code and analysis.
* `Federal_Reserve_Dual_Mandate_Analysis.html` contains the finished visual report.

## Main Finding

The Federal Reserve partially fulfilled its dual mandate. Both selected benchmarks were met during 27% of the available months, showing the difficulty of maintaining price stability and low unemployment at the same time.
